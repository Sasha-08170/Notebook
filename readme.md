# 🍽️ Ресторан "Бем: Вкус Приключений" | Меню

Это Веб-страница с меню ресторана **"Бем: Вкус Приключений"**, которая включает:

- 📖 **Полное меню** с категориями: закуски, основные блюда, десерты, напитки и специальное предложение.
- 🔎 **SEO-оптимизацию** (метатеги `title`, `description`, `keywords`, `author`, `robots`).
- 🌐 **Open Graph и Twitter Cards** для красивого отображения в социальных сетях.
- 📊 **Структурированные данные Schema.org (JSON-LD)** для поисковых систем (Google Rich Snippets).

---

## 🚀 Запуск

1. Клонируйте репозиторий или скопируйте файлы:
   ```bash
   git clone https://github.com/username/bem-menu.git
   cd bem-menu
   ```

2. Откройте файл `index.html` в браузере.
