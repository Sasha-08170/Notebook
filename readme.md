# 🍽️ Ресторан "Бем: Вкус Приключений" | Меню

Этот проект — это Веб-страница с меню ресторана **"Бем: Вкус Приключений"**, которая включает:

- 📖 **Полное меню** с категориями: закуски, основные блюда, десерты, напитки и специальное предложение.
- 🔎 **SEO-оптимизацию** (метатеги `title`, `description`, `keywords`, `author`, `robots`).
- 🌐 **Open Graph и Twitter Cards** для красивого отображения в социальных сетях.
- 📊 **Структурированные данные Schema.org (JSON-LD)** для поисковых систем (Google Rich Snippets).

---

## 🚀 Запуск

1. Клонируйте репозиторий или скопируйте файлы:
   ```bash
   git clone https://github.com/username/bem-menu.git
   cd bem-menu
   ```

2. Откройте файл `index.html` в браузере.



## 📂 Структура проекта

bem-menu/
│── index.html       # Основная HTML-страница с меню и JSON-LD
│── style.css        # Стили страницы
```

## 🔧 Технологии

- **HTML5**
- **CSS3**
- **Google Fonts**
- **Open Graph / Twitter Cards**
- **Schema.org JSON-LD**


## 📊 SEO и микроразметка

- Использованы ключевые слова:
  `ресторан, Бем: Вкус Приключений, меню, закуски, основные блюда, десерты, напитки, кухня, шеф, Киев`
- Микроразметка **Schema.org/Restaurant + Menu**, которая помогает Google правильно индексировать меню.
- Поддержка **Rich Snippets** (цены, категории, названия блюд).
